ENTORNO_FLUTTER

Mapeo técnico y conceptos fundamentales para el desarrollo de aplicaciones multiplataforma con rendimiento nativo.

¿QUÉ ES FLUTTER?

Es un framework de código abierto creado por Google para diseñar e implementar aplicaciones hermosas, compiladas de forma nativa para dispositivos móviles, web, escritorio y sistemas embebidos a partir de una única base de código. Su motor gráfico renderiza cada píxel directamente en la pantalla, asegurando una experiencia fluida y consistente en cualquier sistema operativo.

¿QUÉ ES UN SDK Y QUÉ INCLUYE?

Un SDK (Software Development Kit) es un conjunto de herramientas, librerías, documentación y códigos de ejemplo que los programadores necesitan para desarrollar aplicaciones en una plataforma específica.

El SDK de Flutter incluye:

  • Motor de Renderizado (Skia / Impeller): Compila y dibuja la interfaz directamente.
  • Compilador de Dart: Traduce el código a instrucciones nativas (AOT y JIT).
  • Herramientas de Depuración (DevTools): Herramientas para inspeccionar el árbol de widgets y analizar el rendimiento.
  • Librerías de Widgets: Colecciones completas basadas en Material Design (Android) y Cupertino (iOS).

EL LENGUAJE // DART

Es el lenguaje de programación optimizado para el cliente en el que se escribe Flutter. Ofrece tipado fuerte, recolección de basura automática y capacidades de recarga rápida (Hot Reload) que aceleran el ciclo de desarrollo.

COMPONENTES // WIDGETS

En Flutter, todo es un widget. Son los bloques de construcción básicos de la interfaz; desde un simple texto, una alineación, un color de fondo, hasta pantallas enteras se estructuran mediante el anidamiento de widgets.

ESTADO IMMUTABLE // STATELESSWIDGET

Un widget que no requiere un estado mutable. Se dibuja una sola vez a partir de la configuración inicial y su apariencia no cambia de forma interna durante el ciclo de vida de la pantalla.

ESTADO DINÁMICO // STATEFULWIDGET

Un widget que posee un estado interno dinámico. Permite redibujar la interfaz de forma interactiva en tiempo real cuando los datos o las interacciones del usuario cambian (mediante el método setState()).
